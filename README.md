# TVHub — ТВ-приставка из ноутбука на Windows

Полноэкранная оболочка в стиле Google TV: телеканалы (IPTV), онлайн-кинотеатры, управление пультом.

## Запуск

1. Подключите ноутбук к телевизору кабелем HDMI.
2. Запустите `TVHub.exe`. Установка не нужна.
   - Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без цифровой подписи.
   - Нужен компонент Microsoft Edge WebView2. В Windows 10/11 он обычно уже есть. Если нет, TVHub подскажет, откуда его скачать.
3. Чтобы ноутбук включался сразу в режиме приставки, включите в «Настройки» → «Запускать TVHub вместе с Windows».

## Управление

| Кнопка пульта | Клавиатура | Действие |
|---|---|---|
| Стрелки | Стрелки | Выбор |
| OK | Enter | Открыть |
| Назад | Esc / Backspace | Вернуться |
| Домой | Ctrl+Shift+H | На главный экран **из любого места**, в том числе из открытого Кинопоиска или YouTube |
| Меню | клавиша Menu / F2 | В избранное, переместить или удалить приложение |
| CH+ / CH− | PageUp / PageDown | Переключить канал |
| Цифры | Цифры | Канал по номеру |
| — | F11 | Полный экран вкл/выкл |

Геймпад (Xbox и похожие) и мышь тоже работают.

### Пульт на телефоне
«Система» → «Пульт на телефоне» (или «Настройки» → «Пульт на телефоне») покажет QR-код. Телефон должен быть в той же сети Wi-Fi, что и компьютер.
Наведите камеру телефона на код, и в браузере откроется пульт: крестовина, OK, «Назад», «Домой», громкость, каналы, цифры, тачпад вместо мыши и ввод текста с клавиатуры телефона.
Нажатия приходят в Windows как настоящие нажатия клавиш, поэтому пульт работает в любом окне: в TVHub, в Кинопоиске и YouTube в Edge, в VLC.
При первом запуске Windows может спросить про брандмауэр: разрешите доступ в **частных** сетях.
Страницу пульта удобно добавить на главный экран телефона («Добавить на главный экран» в меню браузера).
На вкладке **«Окна»** видно всё, что открыто на компьютере: любое окно можно вывести на экран или закрыть. Если программа зависла и не закрывается, появится кнопка «Завершить принудительно».

### Приложение «Пульт TVHub» для Android
В «Пульт на телефоне» есть второй QR-код: по нему скачивается `TVHub-Remote.apk`. Приложение открывает пульт сразу, без браузера, помнит компьютер, не даёт экрану погаснуть, а кнопки громкости телефона управляют громкостью компьютера.
Сменить компьютер можно кнопкой «⋯» вверху пульта. Ссылка на последнюю версию: https://github.com/kalinka95/TV-HUB/releases/download/remote-app/TVHub-Remote.apk

### Окна сервисов
Повторное открытие сервиса (Кинопоиск, YouTube…) выводит уже открытое окно. Кнопка «Домой» ставит видео и звук в сервисах на паузу, а окна остаются в фоне. Яндекс Музыка при этом продолжает играть.

## VPN (Happ)

Слева вверху на главном экране есть переключатель «VPN Happ: вкл/выкл» (с «Главной» — стрелка вверх, затем влево, затем OK).
TVHub находит Happ сам; если не нашёл, укажите путь к Happ.exe в «Настройки» → «VPN».
- **Выключить:** TVHub закрывает Happ. Если Happ оставил в Windows настройку прокси, TVHub её сбрасывает, чтобы не пропал интернет.
- **Включить:** TVHub запускает Happ и ждёт подключения. Если VPN не подключился сам, TVHub открывает окно Happ и сам нажимает в нём кнопку подключения. Если кнопку найти не удалось, окно Happ остаётся на экране: нажмите кнопку сами (удобно тачпадом на пульте), затем «Домой».
- Состояние определяется по факту: по сетевому адаптеру VPN или системному прокси. В «Настройки» → «VPN» видно, что именно нашёл TVHub.
- Если Happ запущен от имени администратора, Windows попросит подтвердить закрытие.

Нажатие на переключатель VPN открывает меню: «Включить/Выключить VPN» и «Открыть Happ» (окно Happ выходит на экран).

**Российские сервисы без VPN** (включено по умолчанию, «Настройки» → «VPN»): Кинопоиск, Okko, Wink, Иви, KION, Premier, VK Видео, Rutube, Смотрим и Яндекс Музыка открываются в обход VPN. Если Happ работает в режиме туннеля (весь трафик через VPN, обойти нельзя), TVHub перед открытием такого сервиса сам выключает VPN и присылает уведомление.

Совет: настройте в Happ маршрутизацию, при которой российские сайты идут напрямую (geoip:ru / geosite:category-ru → direct). Тогда переключать VPN не придётся.
В «Система» → «Проверка пульта» видно, что приходит от каждой кнопки.

### Bluetooth-пульт
«Параметры» Windows → «Bluetooth и устройства» → «Добавить устройство» → Bluetooth.
Пульт переводят в режим сопряжения, зажав на 3–5 секунд **OK + Назад**, **Домой + Меню** или **Домой + Назад**.
Если пульт инфракрасный (ИК) или работает только со своим проектором, подойдёт аэромышь на 2.4G с USB-донглом.

## Телеканалы

«Настройки» → «Плейлисты»: вставьте ссылку на M3U-плейлист вашего IPTV-провайдера или путь к файлу (`C:\TV\list.m3u`).
Поддерживаются HLS (`.m3u8`), MPEG-TS и FLV, категории (`group-title`), логотипы (`tvg-logo`) и `#EXTVLCOPT` (User-Agent/Referer).
По умолчанию подключён открытый список iptv-org. Часть каналов в нём может не работать: это публичные потоки.

## Онлайн-кинотеатры

Сайты открываются в Microsoft Edge на весь экран в отдельном профиле, поэтому вход в аккаунт сохраняется.
YouTube открывается в ТВ-версии (youtube.com/tv), ею удобно управлять стрелками.
Сайты Кинопоиска, Okko и других сервисов рассчитаны на мышь, поэтому стрелками ими управлять менее удобно, чем на настоящей приставке.
Вернуться в TVHub можно кнопкой «Домой».

Любой сайт или программу (например, VLC или Steam) можно добавить в «Настройки» → «Приложения».

**Не пускает в аккаунт** («Не удалось войти в аккаунт. Возможно, этот браузер или приложение небезопасны» у Google и YouTube): наведите на карточку сервиса, нажмите «Меню» → «Войти в аккаунт». Сервис откроется в обычном Edge, которому Google доверяет. Войдите, нажмите «Домой», и дальше сервис будет открываться уже с входом.
В ТВ-версии YouTube можно войти и без пароля: «Войти» на экране YouTube покажет код, его вводят на телефоне на странице youtube.com/activate.

## Телепрограмма

Названия передач видны на карточках каналов («что идёт сейчас» и полоска прогресса), в верхней карточке и в плеере.
В плеере **«вправо»** открывает телепрограмму канала на сегодня и завтра. OK на будущей передаче включает напоминание: за минуту до начала TVHub спросит, переключиться ли на неё.
TVHub берёт телепрограмму из плейлиста провайдера (ссылка url-tvg), а если её там нет, пробует открытые источники. Свою ссылку на XMLTV можно указать в «Настройки» → «Телеканалы и телепрограмма».

Названия каналов показываются на русском: «Perviy Kanal (1080p)» → «Первый канал». Выключается там же.

## Погода, уведомления, заставка

- **Погода:** выберите город в «Настройки» → «Погода». Температура видна вверху главного экрана; OK по ней открывает прогноз на 5 дней.
- **Уведомления:** колокольчик вверху (напоминания о передачах, подключение телефона и т.д.). Новые уведомления видны и рядом на главном экране.
- **Заставка:** если 10 минут ничего не нажимать (можно поменять в настройках: от 1 до 30 минут), появятся часы, дата, погода и медленно переливающийся чёрно-синий фон. Любая кнопка возвращает обратно. Включить заставку сразу можно долгим нажатием на обложку трека во вкладке «Музыка» пульта на телефоне.

## Музыка

Вкладка «Музыка» показывает, что сейчас играет на компьютере (название, исполнитель, обложка), и управляет воспроизведением. Кнопка «Открыть Яндекс Музыку» запускает приложение Яндекс Музыки, если оно установлено, иначе — сайт music.yandex.ru.
Кнопка «Домой» Яндекс Музыку не закрывает: музыка играет дальше.

- **Живой визуализатор:** TVHub слушает звук компьютера (то, что идёт на телевизор): внизу экрана музыки — спектр в цветах обложки, обложка подпрыгивает на басах, свечение вокруг неё и фон вспыхивают в такт. Работает с любым плеером, ничего устанавливать не нужно.
- **Перемотка:** стрелкой вниз перейдите на полосу прогресса, затем ← → перематывают трек на 10 секунд. Если держать кнопку, перемотка ускоряется. Трек перематывается, когда кнопку отпустили. На пульте в телефоне полосу можно тянуть пальцем.
- **Мне нравится:** кнопка-сердечко добавляет трек в «Мне нравится» Яндекс Музыки или убирает оттуда. Работает, когда Яндекс Музыка открыта из TVHub (иначе сердечко бледное).
- **Музыка в шторке телефона:** приложение «Пульт TVHub» показывает, что играет на компьютере, в шторке и на экране блокировки: обложка, пауза, треки, перемотка и сердечко. Работает с Яндекс Музыкой и любым другим плеером. Выключается в меню «⋯» пульта.

## Тёмная тема

«Система» → «Тёмная тема» (или «Настройки» → «Тёмная тема»):
- **Тёмная тема Windows и программ** — то же, что «Параметры» → «Персонализация» → «Цвета» → «Тёмный»: Проводник, Параметры, Edge, панель задач и программы, которые следуют теме Windows.
- **Тёмные сайты** — Edge затемняет в окнах сервисов даже сайты без своей тёмной темы. Открытые сайты при переключении закрываются, чтобы настройка применилась.

## Режим администратора

Если пульт с телефона не работает в программах, запущенных от имени администратора (например, в Happ), включите «Настройки» → «Режим администратора». TVHub перезапустится с правами администратора.

## Где хранятся данные

`%APPDATA%\TVHub\` — `config.json` (настройки), `tvhub.log` (журнал), `browser\` (профиль Edge для сервисов).

## Обновления

TVHub проверяет новую версию при запуске и потом каждый час. Если она есть, сразу появляется окно «Доступна новая версия… Обновить сейчас?».
Перед установкой проверяется контрольная сумма файла, прошлая версия сохраняется: её можно вернуть в «Настройки» → «Обновления».

Новая версия выходит сама: достаточно поменять номер в `main.go` (`var appVersion = "…"`) и отправить изменения в ветку `main`. GitHub соберёт TVHub.exe и опубликует его в разделе Releases.

## Сборка из исходников

Нужен Go 1.24+. Собирать можно на любой ОС:

```bash
go install github.com/tc-hib/go-winres@latest
go-winres make --arch amd64
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w -H windowsgui" -o dist/TVHub.exe .
```

Режим разработки на Linux/macOS (интерфейс открывается в браузере): `go run .`, затем откройте ссылку, которую программа выведет в консоль.

Структура:
- `main.go` — сервер, разбор M3U, прокси для потоков;
- `platform_windows.go` — окно WebView2, полный экран, кнопка «Домой», запуск приложений, автозапуск;
- `web/` — интерфейс (HTML/CSS/JS, hls.js, mpegts.js).
